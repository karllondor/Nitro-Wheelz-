# Nitro Wheelz SFX — ready for Godot

17 individually named OGG clips are tracked in this directory. The game script `res://scripts/audio/drive_audio.gd` already references these exact paths. Open [full SFX catalog](../../../docs/audio/SFX_CATALOG.md) for source videos, time ranges, precise intended use and limitations.

Use `res://assets/audio/tyre_drift.ogg` for sustained drift; `tyre_handbrake.ogg` for hydraulic rear lock; `turbo_bov.ogg` when letting off the throttle; `barrier_hit.ogg` for crash. Do **not** use `engine_limiter.ogg` as idle engine audio: no Engine Master was supplied.
