WHAT IT DOES
1. In-game loading screen (`NitroBusy` poster mode, `open(parent, text, small, with_poster)`): the key art fills the screen (fitted by HEIGHT, never stretched; narrow phones lose a little at the sides, the logo is never cropped; wide screens get bars of the art's own edge colour), a dark scrim at the bottom and a slim bar with the spinner, the title / detail ("LOADING TRACK • <track> • <landscape>") and the chequered progress strip. Opened by `boot.gd _go()` (LOADING, when DRIVE / TRACK BUILDER start a scene) and `race.gd _load_terrain()` (LOADING TRACK). Other busy overlays (GENERATING TERRAIN, SMOOTHING TRACK, the compact UPDATING TERRAIN pill, FINDING A ROUTE …) are unchanged; if the art is missing the plain card is used.
2. Boot splash (`project.godot`, first frame after the Android system splash): the engine accepts ONLY a PNG (a JPEG is rejected with "The only supported format is PNG" and the Godot logo shows), so `boot_splash.png` is a 720x1600 9:20 crop of the art with feathered edges (bars on other aspect ratios blend into `bg_color`), `stretch_mode = 3` (Keep Height; engine 4.7 replaced `fullsize` by `stretch_mode`), `minimum_display_time = 800 ms` so it can actually be seen. The boot is ~0.8 s longer only when the engine itself starts faster than that.
