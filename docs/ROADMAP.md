# Progressive delivery gates

P0 Foundation: Git & protected-art gate, pinned engine, import and smoke CI, input actions/monitor, safe initialization and diagnostics.
P1 Production: versioned release packaging, target-specific exports, Android touch implementation, runtime replay, visual regression, screenshot/video evidence and performance measurements.
P2 Optional modules: Blender validation, localisation, saves/migrations, audio manager, rebinding, telemetry, multiplayer and genre-specific controllers.

Gate A: structure and Python negative tests. Gate B: engine import + real scenes. Gate C: hardware and per-platform QA. Gate D: immutable release and tested build evidence.
Do not claim an unexecuted gate as complete. Don't build all optional modules into quick prototypes.
