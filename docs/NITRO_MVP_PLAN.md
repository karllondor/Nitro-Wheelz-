# Nitro Wheelz: v0.1 → v0.5 milestones

**v0.1.0 Driving Lab**
One fictional Japanese circuit, one original prototype RWD car, deterministic two-axle driving, 3-lap timer, score, top-down/chase, wheel/keyboard/touch control, debug and CI. Quality gate: reliable drift angle control, scene import and crash-free keyboard/controller/mobile sessions. This is the current scope.

**v0.2.0 Competition**
Safe lap checkpoint detection (forward-only), penalty handling, top-three records, ghost replay with per-track splits, drift transitions and controller assist tuning.

**v0.3.0 Japanese Circuits**
Original Ebisu/Nikko/Meihan-inspired routes, expanded environment layering and both daylight/night variants. No copying official layouts.

**v0.4.0 Dream Garage**
Save data, ownership, fictional JDM car variants, different wheelbase/power/grip configurations, currency and visual tuning. No pay-to-win.

**v0.5.0 Night Ride**
Midnight Touge circuit, production engine audio, headlight cones, reflections, adjustable effects and optional nitro system balanced against tire grip.

Creator packs: only with signed license agreement for NIGHTRIDEPL / Drift Games names and cars, no assumption of partnership.
