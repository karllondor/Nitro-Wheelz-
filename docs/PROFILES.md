# Production profiles

quick-2d: Godot starter menu + one mechanic, 2D assets, minimal CI, keyboard/pad input. Add Android touch if Android targeted.

cinematic-2.5d: 2D actors and 3D world/camera, layering, consistent sprites, occlusion, art lock, camera motion benchmark.

3d-production: Blender scene exports, metre-scale assets, mesh/UV/LOD/collision, camera/lighting, physics + performance benchmark.

These are PROCESS profiles only. They don't install a platformer/racing engine. Keep one core template; implement optional feature packs when needed.
