# Poland — Nitro Wheelz visual reference library

**Actual images:** Drive / Nitro Wheelz / Visual References / poland. Use [SHA inventory](../MANIFEST.csv) and [master index](../README.md).

## Locations

- **Ojcow Canyon / Golden Autumn:** 4 landscape visualizations, 1 concept board, 1 asset pack. Golden deciduous forests, fallen leaves, limestone outcrops, valleys, distant Pieskowa Skała/Ojców-inspired landmarks. [Part 1](https://drive.google.com/file/d/1eiKLNCVUgIAUjWq98zzVI62whDhZ3oxJ/view?usp=drivesdk) · [Part 2](https://drive.google.com/file/d/1H78o3psQMqdl0zDtbO7fVBI5evvuJfHD/view?usp=drivesdk).
- **Tatry mountain:** 3 track visualizations and 1 asset pack. Granite and steep alpine rock, mountain serpentines, pine forest belts, retaining walls and mist. [Tatry references](https://drive.google.com/file/d/1osMIWUkKZMuGzzDomLawYAynXekKYivY/view?usp=drivesdk).

**Owner-approved constraints:** Real Polish golden-autumn palette for Ojcow; limestone there, but high-mountain granite in Tatry. Do not mix Japanese torii, Japanese houses, or random generic village rows along the road. Built track service structures go in paddock/functional zones.
