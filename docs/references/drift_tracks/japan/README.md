# Japan — Nitro Wheelz visual reference library

**Actual image storage:** Google Drive / Nitro Wheelz / Visual References / japan. Images are original concept boards, not model files. Read the parent [reference index](../README.md) and [manifest](../MANIFEST.csv).

## Locations

- **Sakura Circuit:** spring blossoms, pink petals and Japanese forest; reference assets 9 + visualizations 2. [Part 1](https://drive.google.com/file/d/1tXqNMQ-BR6JW-8Pt9RtDouZTjj8lwROk/view?usp=drivesdk) · [Part 2](https://drive.google.com/file/d/1E-yMycO4GRONYDpGbT_wc1jFFssKADTF/view?usp=drivesdk)
- **Touge Mountain / Ebisu-Gunsai atmosphere:** steep wooded slopes, serpentine hairpins, rock cuts and retaining structures; assets 3 + visualizations 8. [Part 1](https://drive.google.com/file/d/1u_mrAKmeNeaWboVGZtNCewepn57gOApr/view?usp=drivesdk) · [Part 2](https://drive.google.com/file/d/19SJXLHHSZqTBNLmHkq67MVfEzAHANX63/view?usp=drivesdk)
- **City Track:** modern high-rise Japan, expressways, dense buildings, protected drift-event circuit; 4 visualizations. [City references](https://drive.google.com/file/d/1ZhyvgkGxnlZUoJT3G_TTXPGc4d-YTetH/view?usp=drivesdk)
- **Overview:** 2 architecture/roadside asset boards. [Japan overview](https://drive.google.com/file/d/1nOm5qcrsL0JZliv6hd1ysPhQaJlZmKRf/view?usp=drivesdk)

**Owner-approved art direction:** Japan Sakura gets substantial pink blossoms in spring; Touge may have forested cliff routes and sparing context-appropriate traditional structures in the distance. City Track MUST use recognizable Japanese urban blocks and skyscrapers. No repetitive generic square residential boxes glued to track boundaries. Motifs from mismatched concept boards are illustrative only, not required in every region.
