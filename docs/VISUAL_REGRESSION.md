# Visual and gameplay evidence

Keep scripted camera/lighting/state fixtures and capture short video plus stills BEFORE/AFTER significant changes. Compare approved silhouettes, pivots, shadows, parallax, UI safe areas and depth sorting. Screenshot pixel diff is advisory: different GPUs may legitimately render different pixels. Record renderer/GPU/resolution and actual game version. No 'looks tested' claim from a static render alone.

Reference screenshots live in assets/references, gameplay captures go in ignored captures/ and CI artifacts.
